Require all CI checks on the exact commit before merge. Ledger contention must roll back the entire business transaction; retry with the same idempotency key. NFC is intentionally unavailable outside tests until certified acquiring is integrated; internal identifiers are not issuer authorization codes. Production compose binds 8080 to host loopback: terminate TLS at trusted ingress. Supply a TLS-enabled PostgreSQL endpoint with sslmode=verify-full and a trusted CA; the included local DB does not provision TLS. The exact Java OpenTelemetry suppression is time-limited and based on the published npm advisory. Do not suppress unrelated findings.

Remaining: versioned partner fees, certified NFC acquiring, lease renewal and fencing at every lock consumer, TLS database provisioning and enforcement, branch protection and signed commits, image scanning, secure EMTECH and rail live testing, restore and disaster recovery, independent penetration testing. No certification or live payment success is implied.

MTN now requires explicit ELEPAY_MTN_FEE_BPS and ELEPAY_MTN_FEE_CAP_MINOR when enabled; the arithmetic is overflow-safe. Confirm the contract and reconcile actual provider fees; direction-specific and transaction-versioned schedules remain work. The production startup guard now rejects JDBC URLs without sslmode=verify-full and ambiguous verification overrides. The coordination lock has owner-bound lease renewal and loss reporting; fencing at every consumer's authoritative write boundary remains open.

Runtime image scanning now gates CI with a verified upstream commit pin and a high/critical threshold, including findings without fixes. Production configuration validation now activates when production is declared even if a non-production Spring profile is accidentally enabled. The EMTECH workflow is manually triggered on main, requires GitHub secrets, and fails when the live sandbox test produces no evidence. CodeQL static analysis is a separate verification workflow. None of these additions proves external authorization or a successful scan until CI results exist.
